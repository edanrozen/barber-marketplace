# apps/

Client applications. All are **Hebrew-only, full RTL** from day one.

- `customer-mobile/` — customer app (React Native / Expo)
- `barber-mobile/` — professional app (React Native / Expo)
- `admin-web/` — admin & support console (Next.js + Refine)

Scaffolding of each app happens in later Sprint-1 tasks (E11 app shells). Business rules live server-side; these are thin clients.
